# Patent Writer — Skill de Documentação de Patentes

Skill especializada na redação de documentação de propriedade intelectual
conforme normas INPI e padrões internacionais PCT.

## Tipos de Documentos

### 1. Pedido de Patente de Invenção (PI)
- Relatório descritivo
- Reivindicações (independentes e dependentes)
- Resumo
- Desenhos/figuras técnicas (descrição)
- Listagem de sequências (quando aplicável)

### 2. Pedido de Modelo de Utilidade (MU)
- Para melhorias funcionais em objetos de uso prático

### 3. Documentação Complementar
- Relatório de busca de anterioridade
- Opinião sobre patenteabilidade
- Resposta a exigências INPI
- Documento de prioridade para PCT

### 4. Lei do Bem — Documentação Fiscal
- Relatório técnico de atividades de P&D
- Formulário MCTI para incentivos fiscais
- Classificação de dispêndios (pesquisa básica, aplicada, desenvolvimento experimental)
- Documentação de horas técnicas e recursos

## Estrutura do Pedido de Patente (INPI)

```
1. RELATÓRIO DESCRITIVO
   1.1 Campo da Invenção
   1.2 Fundamentos da Invenção (estado da técnica)
   1.3 Problemas do Estado da Técnica
   1.4 Objetivos da Invenção
   1.5 Sumário da Invenção
   1.6 Breve Descrição dos Desenhos
   1.7 Descrição Detalhada das Realizações Preferidas
   1.8 Exemplos de Realização

2. REIVINDICAÇÕES
   2.1 Reivindicações Independentes
   2.2 Reivindicações Dependentes

3. RESUMO (máximo 200 palavras)

4. DESENHOS (descrição textual detalhada)
```

## Regras de Redação

### Linguagem de Patente
- Usar termos precisos e consistentes ao longo do documento
- Definir todos os termos técnicos na primeira menção
- Evitar linguagem relativa ("aproximadamente", "cerca de") exceto quando necessário
- Usar "compreendendo" (aberto) vs "consistindo de" (fechado) estrategicamente
- Reivindicações em uma única sentença, sem ponto final intermediário
- Numerar sequencialmente todas as reivindicações

### Reivindicações — Melhores Práticas
- **Independentes**: Amplas mas defensáveis, com mínimo de elementos essenciais
- **Dependentes**: Progressivamente mais específicas, criando camadas de proteção
- Reivindicar: método, sistema/dispositivo, produto, uso, e composição quando aplicável
- Mínimo de 10-15 reivindicações para proteção robusta

### Busca de Anterioridade
- Classificar por CPC (Cooperative Patent Classification)
- Buscar em: INPI, USPTO, EPO, WIPO
- Documentar diferenças do estado da técnica
- Fundamentar inventividade e novidade

## Domínios Técnicos Prioritários

### Inteligência Artificial & Computação
- Arquiteturas neuromórficas (ex: inferência LLM)
- Sistemas de IA para diagnóstico médico
- Processamento de linguagem natural
- Visão computacional aplicada à saúde

### Criptografia & Segurança
- Criptografia pós-quântica
- Sistemas de criptografia baseados em cristais ópticos
- Protocolos de autenticação
- Segurança de infraestrutura

### Dispositivos Médicos & Saúde
- Equipamentos de análise corporal
- Sistemas de monitoramento remoto
- Dispositivos de purificação de ar para ambientes clínicos
- Instrumentação para diagnóstico

### Materiais Avançados & Energia
- Baterias com química avançada (cálcio-oxigênio)
- Design biomimético aplicado a materiais
- Nanomateriais funcionais
- Sistemas de armazenamento de energia

## Classificação CPC Relevante

| Código | Área |
|--------|------|
| G06N | Sistemas de computação baseados em modelos computacionais específicos (IA) |
| G06F | Processamento de dados digitais |
| H04L 9/ | Arranjos de criptografia |
| A61B | Diagnóstico; Cirurgia; Identificação |
| H01M | Processos ou meios para conversão de energia química em elétrica (baterias) |
| B01D | Separação (purificação de ar) |
| G02F | Dispositivos ópticos (cristais) |

## Template de Reivindicação

```
1. [Tipo de invenção] CARACTERIZADO POR compreender:
   a) [primeiro elemento essencial];
   b) [segundo elemento essencial];
   c) [terceiro elemento essencial];
   em que [relação funcional entre os elementos].

2. [Tipo de invenção], de acordo com a reivindicação 1,
   CARACTERIZADO POR [especificação adicional].
```

## Lei do Bem — Classificação de P&D

Para enquadramento na Lei 11.196/2005:

| Categoria | Definição | Incentivo |
|-----------|-----------|-----------|
| Pesquisa Básica | Trabalho experimental/teórico sem aplicação prática prevista | 160% exclusão |
| Pesquisa Aplicada | Conhecimento novo dirigido a objetivo prático | 160% exclusão |
| Desenvolvimento Experimental | Trabalhos sistemáticos usando conhecimento existente | 160% exclusão |
| Patente concedida | Bonus por obtenção de patente | +20% (180%) |

### Relatório Técnico Lei do Bem
```
1. IDENTIFICAÇÃO DO PROJETO
2. DESCRIÇÃO TÉCNICA
   2.1 Desafio tecnológico
   2.2 Atividades realizadas
   2.3 Resultados obtidos
3. CLASSIFICAÇÃO (pesquisa básica/aplicada/desenvolvimento)
4. DISPÊNDIOS
   4.1 Recursos humanos (horas técnicas)
   4.2 Materiais e insumos
   4.3 Equipamentos
   4.4 Serviços de terceiros
5. INDICADORES DE RESULTADO
```

## Fluxo de Geração

1. **Identificar** o tipo de documento e domínio técnico
2. **Coletar** descrição técnica da invenção
3. **Realizar** análise de patenteabilidade (novidade, inventividade, aplicação industrial)
4. **Redigir** relatório descritivo com linguagem de patente
5. **Estruturar** reivindicações em camadas de proteção
6. **Gerar** resumo (≤200 palavras)
7. **Classificar** CPC e verificar anterioridades
8. **Formatar** documento final conforme normas INPI

## Exemplos de Uso

- "Redija o pedido de patente para o sistema AMYGDALA de inferência neuromórfica"
- "Crie as reivindicações para o CrystalShield — criptografia com cristais ópticos"
- "Monte o relatório técnico Lei do Bem para os projetos de P&D deste ano"
- "Estruture o pedido de patente para o sistema de purificação de ar com filtração ativa"
- "Gere documentação PCT para internacionalização da patente de baterias Ca-O2"
